# Tartilm — تطبيق أندرويد

تطبيق لحفظ القرآن ومراجعته بالتصحيح الصوتي على رواية ورش عن نافع (6 سور حاليًا).

## الطريقة 1 — الحصول على ملف APK (بدون تثبيت أي برنامج)

لا يمكن بناء الـ APK على الحاسوب بدون Android SDK، لذلك نستعمل GitHub الذي يبنيه لك مجانًا.

1. أنشئ حسابًا على github.com، ثم **New repository** (اسمه `tartilm`، خاص أو عام).
2. فكّ هذا الملف المضغوط، ثم ارفع **كل محتوياته** إلى المستودع (Add file → Upload files).
   تأكد أن المجلد المخفي `.github` مرفوع أيضًا.
3. افتح تبويب **Actions** ← **Construire l'APK** ← **Run workflow**.
4. بعد حوالي 5 إلى 10 دقائق افتح التشغيل الناجح وحمّل الملف **tartilm-apk** من قسم Artifacts، ثم فك ضغطه.
5. انقل `app-debug.apk` إلى الهاتف وثبّته (اسمح بالتثبيت من مصدر غير معروف عند الطلب).
   عند أول تلاوة بالصوت يطلب التطبيق إذن الميكروفون.

الـ APK هذا موقّع للتجربة (debug)، ولا يصلح للنشر على Google Play.

## الطريقة 2 — بدون APK (تثبيت من Chrome)

ارفع مجلد `www` إلى أي استضافة HTTPS (GitHub Pages أو Netlify)، ثم افتح الرابط في Chrome على أندرويد
واختر **تثبيت التطبيق**. يعمل بدون إنترنت بعد أول فتح.

## الطريقة 3 — Android Studio

افتح مجلد `android` في Android Studio، ثم Build → Build APK(s).
بعد أي تعديل في `www` شغّل `npm install` ثم `npx cap sync android`.

## ملاحظات

- التعرف الصوتي في الـ APK يستعمل محرك أندرويد (`ar-SA`) عبر إضافة `@capacitor-community/speech-recognition`.
  يحتاج إنترنت على أغلب الهواتف، وهو غير مدرّب على ورش: يقارن الكلمات فقط ولا يكشف أحكام التجويد.
- الخطوط (Amiri Quran وFigtree، رخصة OFL) مدمجة، فالتطبيق يعمل بدون إنترنت ما عدا التعرف الصوتي.
- البيانات (الجلسات، الأخطاء، العلامات) محفوظة في الهاتف فقط.
